# Version Control Manager Skill

> 项目版本控制与管理技能 - 提供完整的版本创建、回滚、变更记录功能

---

## 📋 技能概述

### 功能描述

`version-control-manager` 是一个强大的项目版本控制与管理技能，旨在帮助开发者高效管理项目的多个版本，支持版本创建、回滚、变更追踪等核心功能。

### 核心特性

| 特性 | 说明 |
|------|------|
| **版本创建** | 支持语义化版本号，自动生成唯一标识符 |
| **版本回滚** | 安全回滚到历史版本，自动创建回滚前快照 |
| **强制版本说明** | 必须填写功能说明、改进点、兼容性等信息 |
| **变更记录** | 完整记录版本间修改内容与时间戳 |
| **自动版本创建** | 检测构建/提交/CI完成事件，经用户确认后自动创建 |

### 应用场景

- **项目发布管理**: 在每次发布前创建版本快照
- **开发回溯**: 快速回滚到稳定版本
- **团队协作**: 追踪团队成员的代码变更
- **CI/CD集成**: 构建成功后自动创建版本

## 🚀 使用方法

### 命令接口

#### 1. 创建新版本

```bash
vc create <版本号> [选项]
```

**参数说明**:

| 参数 | 缩写 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| `<版本号>` | - | string | 是 | 语义化版本号，如 `v1.0.0` |
| `--name` | `-n` | string | 否 | 版本名称 |
| `--description` | `-d` | string | 否 | 版本描述 |
| `--features` | `-f` | string | 是 | 新增功能，逗号分隔 |
| `--improvements` | `-i` | string | 否 | 改进点，逗号分隔 |
| `--known-issues` | `-k` | string | 否 | 已知问题，逗号分隔 |
| `--compatibility` | `-c` | string | 是 | 兼容性信息 |

**示例**:
```bash
vc create v1.0.0 -n "初始版本" -f "用户登录,数据导入" -i "性能优化" -k "移动端适配待完善" -c "Python 3.8+"
```

#### 2. 查看版本列表

```bash
vc list [选项]
```

**参数说明**:

| 参数 | 缩写 | 说明 |
|------|------|------|
| `--all` | `-a` | 显示所有版本 |
| `--limit <数量>` | `-l` | 限制显示数量（默认10） |

**示例**:
```bash
vc list
vc list -a
vc list -l 5
```

#### 3. 查看版本详情

```bash
vc show <版本号>
```

**示例**:
```bash
vc show v1.0.0
```

#### 4. 版本回滚

```bash
vc rollback <版本号>
```

> **注意**: 回滚前会自动创建当前状态的版本快照

**示例**:
```bash
vc rollback v0.9.0
```

#### 5. 删除版本

```bash
vc delete <版本号>
```

> **注意**: 不能删除当前活跃版本

**示例**:
```bash
vc delete v0.8.0
```

#### 6. 查看变更记录

```bash
vc changelog [选项]
```

**参数说明**:

| 参数 | 缩写 | 说明 |
|------|------|------|
| `--from <版本号>` | `-f` | 起始版本 |
| `--to <版本号>` | `-t` | 结束版本 |

**示例**:
```bash
vc changelog
vc changelog -f v1.0.0 -t v2.0.0
```

#### 7. 自动版本创建配置

```bash
vc auto [enable|disable|status]
```

**示例**:
```bash
vc auto enable    # 启用自动版本创建
vc auto disable   # 禁用自动版本创建
vc auto status    # 查看状态
```

## 🔧 故障排除

### 常见错误及解决方法

| 错误代码 | 错误信息 | 原因 | 解决方法 |
|----------|----------|------|----------|
| VC001 | 版本号格式无效 | 版本号不符合语义化规范 | 检查版本号格式，如 `v1.0.0` |
| VC002 | 版本已存在 | 相同版本号已存在 | 使用其他版本号 |
| VC003 | 版本不存在 | 指定的版本号不存在 | 确认版本号正确 |
| VC004 | 无法回滚到当前版本 | 尝试回滚到当前版本 | 选择其他版本 |
| VC005 | 缺少必填字段 | 未提供必需的版本信息 | 补充 `--features` 和 `--compatibility` |
| VC006 | 权限不足 | 无权限执行操作 | 联系管理员 |

cat .version-control/changelog.json
